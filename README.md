# Portfolio — Sergio Trúebano

Portafolio personal desplegado en [Netlify](https://sergiotr.netlify.app).

[![Netlify Status](https://api.netlify.com/api/v1/badges/c4ac97fa-0bac-440f-995e-28023dad0510/deploy-status)](https://app.netlify.com/projects/sergiotr/deploys)

## Stack

- [Astro](https://astro.build/)
- [Tailwind CSS](https://tailwindcss.com/)
- [TypeScript](https://www.typescriptlang.org/)

## Commands

| Command | Action |
| :------ | :----- |
| `npm install` | Instala dependencias |
| `npm run dev` | Servidor de desarrollo en `localhost:4321` |
| `npm run build` | Build de producción en `./dist/` |
| `npm run preview` | Vista previa del build |
